How the controller stops the flood

Learn & forward. Packet-in messages teach the controller which MAC sits on which port; it installs prio 100 forwarding flows.
Poll port stats. Every 1 s the controller reads OpenFlow per-port counters — one port per host, so a port rate is a per-source rate.
Detect. Any port above 1000 pps is flagged. Port 4 hits 39,062 pps and trips at t = 11.0 s.
Mitigate. A prio 200 in_port=4 → DROP flow-mod blocks the attacker at the switch; legit traffic reaches the server again.

Every rate, timestamp and delivery figure above is replayed from real output of the ns-3 / OFSwitch13 project (monitor-stats.csv, detections.csv, flowmon.xml). Regenerate it with ./ns3 run ddos-mitigated and ./ns3 run ddos-attack. The moving packets are a visualization of the measured flows, not a packet-by-packet trace.
