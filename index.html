What the advanced controller does

Per-source stats. Polls OpenFlow flow-stats and sums by eth_src, so it measures each host even when several share one switch port.
Multi-signal + adaptive. Flags a source only when its rate beats an adaptive baseline threshold and its packets are small (floods use tiny packets).
Two-stage block. Coarse in_port DROP first, then a surgical ip_src DROP — freeing the innocent client sharing the attacker's port.
Penalties. Each offense is held down longer (5s→20s→…); after 3 strikes the source is permanently BLACKLISTED.

Every rate, event and delivery figure is replayed from real ns-3 / OFSwitch13 output (monitor-stats.csv, detections.csv, metrics.csv, flowmon.xml) of the ddos-advanced experiment. Rebuild it with python3 scripts/analysis/build_dashboard.py. Rate-limiting via OpenFlow meters (instead of an outright drop) is documented future scope.
